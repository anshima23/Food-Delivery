## 🚀 Overview

Welcome to our Food Delivery App, where we are redefining the way people experience food delivery. While the concept of ordering food online is nothing new, we’ve added some exciting features to make this app more intuitive, efficient, and secure than other food delivery services.

Whether you're craving pizza, sushi, or a cozy homemade meal, our app allows users to explore a wide variety of restaurants, customize orders, track deliveries in real-time, and receive personalized food recommendations. All these features come packaged with a sleek and easy-to-use interface that will change the way you think about food delivery
What sets us apart?
- Advanced AI-powered Recommendations: Say goodbye to endless scrolling! Our app learns your preferences and recommends the perfect dish for you every time you order.

- Real-time Tracking: Track your order from kitchen to doorstep with live updates.

- Dietary Preferences & Filters: Easily filter dishes based on your dietary preferences such as vegan, keto, gluten-free, or low-carb options.

## ✨ Features

- 🍔 Personalized Food Recommendations: The app learns your preferences and shows you food items that match your tastes.

- 🥗 Dietary Filters: Choose food based on your dietary needs, whether you’re vegan, gluten-free, or on a keto diet.

- 🚴 Real-Time Delivery Tracking: Track your order in real-time with live updates from restaurant to doorstep.

- 🍽️ Restaurant & Menu Discovery: Explore local and international restaurants with ease.

- 🛡️ Secure Payment Integration: With trusted payment gateways, you can pay easily and securely.

## 🛠 Installation

```sh
# Clone the repository
git clone https://github.com/yourusername/food-delivery-app.git
cd food-delivery-app

# Install dependencies
# For the backend, run:
cd backend
npm install

# For the frontend, run:
cd client
npm install

#Run the Application
#Backend Setup
cd backend
npm start

Frontend Setup
cd client
npm start
```

## 📚  Learning Goals
This project provides a great learning opportunity by:

- Developing a fully integrated food delivery platform with real-time updates.
- Understanding the intricacies of user experience in e-commerce and food delivery services.
- Expanding knowledge of both frontend (React) and backend (Node.js, Express) development.
- Exploring secure payment integration and real-time notifications

## 🎯 Issues & Limitations
🚧 Limited Feature Set: While we’ve implemented the basics of food delivery, future releases may include enhanced search functionality, customer feedback options, and an option to pre-order meals.

🚧 Mobile Optimization: While the app is mobile-friendly, some components can be improved for smoother use on smaller devices.
